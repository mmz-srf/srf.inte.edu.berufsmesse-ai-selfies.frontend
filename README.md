# srf.inte.edu.berufsmesse-ai-selfies.frontend
Backend für die Generierung von Sammelkarten-Selfies mit AI

## Running the project

Run `npm i` to install all dependencies

---

### Development Enviroment

Run `npm run dev`
Visit [http://localhost:3000](http://localhost:3000)

---

### Production with HTTPS (Self signed SSL)

Run `npm run build` and `npm run start:https`
Visit [https://localhost:3000](https://localhost:3000)

> [!IMPORTANT]  
> Requires `192.168.2.1-key.pem` and `192.168.2.1.pem` files in the root directory to work.

---

### Production with HTTP

Run `npm run build` and `npm start`
Visit [http://localhost:3000](http://localhost:3000)
